# Project Documentation Index

This folder contains useful documentation files for managing a real-world project.

## Available documents

- [architecture-overview.md](architecture-overview.md) - high-level overview of the app, its modules, and technical decisions
- [development-setup.md](development-setup.md) - local setup instructions, dependencies, and run commands
- [coding-standards.md](coding-standards.md) - conventions for naming, formatting, component structure, and code style
- [api-conventions.md](api-conventions.md) - guidance for handling API requests, responses, error handling, and loaders
- [deployment-guide.md](deployment-guide.md) - checklist and notes for building and deploying the app
- [changelog.md](changelog.md) - change history for the project

## Recommended usage

Keep these files updated as the project grows. They are especially helpful when:
- onboarding new developers
- handing the project to another team member
- preparing for deployment
- reviewing structure and conventions later
