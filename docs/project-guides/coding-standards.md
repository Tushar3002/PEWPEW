# Coding Standards

## General principles
- Write readable code first
- Prefer small, focused components
- Avoid duplicated logic
- Keep files organized by responsibility

## Naming conventions
- Components: PascalCase, for example UserTable.jsx
- Hooks: useSomething.js
- Utilities: camelCase.js
- Constants: constants.js or feature.constants.js
- Pages: FeatureName.jsx

## Component guidelines
- Keep components small and reusable
- Avoid mixing UI rendering with API calls when possible
- Use descriptive prop names
- Keep props simple and predictable

## Styling guidelines
- Prefer consistent class naming
- Avoid excessive inline styles
- Keep global CSS usage limited where possible

## Code quality
- Remove unused imports and dead code
- Keep comments purposeful and minimal
- Use meaningful variable names
